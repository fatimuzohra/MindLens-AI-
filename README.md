# MindLens AI 🌿
### An Offline AI-Powered Mental Wellness Companion

MindLens AI is an AI-powered mental wellness companion designed to help individuals understand their emotions, manage everyday stress, reflect on their experiences, and build healthier emotional habits in a safe and supportive environment.

The project aims to provide a private and accessible AI companion using locally running Large Language Models (LLMs), reducing dependence on cloud-based AI services.

## 🌱 Project Vision

To create a supportive AI companion that helps people understand themselves better, express their feelings freely, and receive personalized emotional wellness support without judgment or pressure.

## ✨ Key Features

- **AI Friend:** An interactive AI companion for natural and supportive conversations.
- **Emotional Support:** Helps users express feelings, reflect on experiences, and understand their emotional patterns.
- **Mood Tracking:** Daily emotional check-ins and mood monitoring.
- **Personalized Experience:** User onboarding and personalized interactions.
- **Multiple Support Modes:** Listening, understanding yourself better, calming anxiety, distraction, and reflecting on past experiences.
- **Safety Detection:** Identifies potentially concerning messages and provides appropriate safety guidance.
- **Voice Interaction:** Planned voice-based conversations and speech interaction.
- **Privacy-Focused:** Designed around local AI inference and private user interactions.

## 🧠 AI and Technical Approach

MindLens AI explores the integration of:

- Large Language Models (LLMs)
- Natural Language Processing (NLP)
- Emotion and sentiment analysis
- Prompt engineering
- Retrieval-Augmented Generation (RAG) — planned
- Local AI inference
- Personalized AI interactions

## 🛠️ Technology Stack

The project is being developed using:

- Python
- HTML, CSS and JavaScript
- FastAPI / Flask (backend architecture)
- Local LLMs
- Gemma model
- Ollama / llama.cpp
- NLP and Machine Learning

*The technology stack and architecture are under active development.*

## 🔒 Privacy and Safety

MindLens AI is designed as a non-diagnostic wellness support tool. It does not replace professional mental healthcare, diagnosis, or emergency services.

Privacy, responsible AI behavior, user independence, and safety are important design principles.

## 🚧 Project Status

**Currently under development.**

More features, documentation, and implementation details will be added as development progresses.
